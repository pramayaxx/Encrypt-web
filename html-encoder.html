ENC

HTML Encoder / Simple Encryptor

Paste HTML, give an encryption key, press Encode. A reversible XOR+Base64 encoder is used (client-side only).

This file is a local, client-side tool — nothing leaves your browser unless you copy/share the output.
Algorithm used: UTF-8 bytes → XOR with key bytes (repeated) → Base64. Decoding reverses the steps.
